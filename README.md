# Słówka B1 — картки польська → English (версія 1.2)

Android-застосунок для вивчення слів рівня B1 (для технікуму в Польщі). **Інтерфейс повністю польською.**
Біле меню, картки з 3D-переворотом, база даних SQLite, чорний список, партії по 50 слів, власні зестави,
серія днів 🔥, тест із вписуванням слів і щоденні нагадування. Без інтернету, без реклами, без зовнішніх бібліотек.

## Що нового у 1.2

- **Правильне слово в тесті зникає з тестів одразу**, не треба чекати кінця тесту й 100 %. Помилкові слова залишаються й повертаються в наступному тесті; кнопка «Powtórz błędne» на екрані результату проганяє тільки їх. Якщо вийти з тесту посередині, вже вірно відповідені слова лишаються зарахованими.
- **Кілька перекладів.** Якщо слово має кілька перекладів (наприклад `flat / apartment`) і ти вписав один, застосунок покаже решту: «Drugie tłumaczenie: apartment». Це стосується 237 слів словника.
- Виправлено: переклад у дужках (`to change (trains / buses)`) більше не розбивається на хибні частини.

## Що було в 1.1

- **Усе по-польськи**: кнопки, повідомлення, діалоги, сповіщення.
- **Анімації**: 3D-переворот картки, ковзання зі злегка нахилом при гортанні, «виліт» картки на чорний список і поява нової з відскоком, трясіння картки при помилці в тесті.
- **Серія 🔥 як у Duolingo.** Картка вгорі головного екрана: скільки днів поспіль виконано ціль, прогрес за сьогодні та смужка останніх 7 днів. Ціль — **2 різні слова на день**. Слово зараховується, коли ти:
  - перевернув картку й побачив переклад, **або**
  - відправив слово на чорний список, **або**
  - правильно відповів на нього в тесті.

  (Кількість слів на день міняється константою `DAILY_GOAL` у `Db.java`.)
- **Тест (Test sprawdzający).** Бачиш польське слово — вписуєш англійське.
  - У тест потрапляють **усі слова з чорного списку, які ще не пройшли тест**. Правильно відповідене слово **зникає з тестів одразу**.
  - Регістр не важливий (`Apple` = `apple`). Також не важливі пробіли по краях, дефіси, апострофи й діакритика (`fiance` = `fiancé`).
  - Якщо в базі кілька варіантів через «/» (наприклад `flat / apartment`), досить вписати будь-який. Текст у дужках можна пропускати. У дієслів «to» необов'язкове (`rent` = `to rent`).
  - **Помилка в літері = помилка**: слово не зараховується, і застосунок показує правильну відповідь.
  - Зараховане слово залишається на чорному списку (на картках не з'являється), але **більше не потрапляє в тести**. Слова з помилкою лишаються й повертаються в наступному тесті (кнопка «Powtórz błędne»).
- **Лічильники.** На головному екрані й на екрані «Czarna lista» видно, скільки слів на чорному списку і скільки з них **ще чекають на тест**. На самому чорному списку біля кожного слова позначка «✓ zaliczone w teście» або «czeka na test».
- **Пропозиція тесту**: коли набирається **50** слів, що чекають на тест, застосунок сам пропонує пройти його, потім знову на **60, 70, 80…** (або «Później», і наступне нагадування на +10).
- **Нагадування** (як сповіщення від Duolingo):
  - щодня о вибраній годині (за замовчуванням 18:00), **якщо ціль на сьогодні ще не виконана**;
  - плюс «остання нагода» о 21:30, **тільки коли є серія, яку можна втратити**;
  - **100 різних фраз** польською у `app/src/main/assets/phrases.txt` (20 з них згадують твою серію). Одна й та сама фраза двічі поспіль не приходить;
  - годину й вмикання/вимикання змінюєш кнопкою «🔔 Przypomnienia» внизу головного екрана.
  - На Android 13+ при першому запуску дозволь сповіщення.
  - На деяких телефонах (Xiaomi, Huawei, Samsung, Oppo) економія батареї блокує нагадування: у налаштуваннях телефону вимкни для застосунку оптимізацію батареї.

## ⚠️ Важливо при першому встановленні 1.1

Версія 1.0 була підписана випадковим ключем GitHub, а тепер ключ **фіксований** (`app/debug.keystore`).
Тому **один раз** Android не дасть поставити 1.1 поверх 1.0 («Aplikacja nie została zainstalowana»):

1. Видали стару версію з телефону (прогрес 1.0, чорний список і власні зестави, при цьому зникне).
2. Постав нову.

Усі наступні оновлення вже ставитимуться **поверх** без втрати даних.

> Якщо репозиторій публічний, ключ підпису видно всім. Для особистого застосунку це не страшно, але надійніше зробити репозиторій приватним.

## Як користуватись

- **Partia B1** — 50 слів. Вчиш, доки всі не підуть на чорний список, потім автоматично береться наступна партія з 50.
- **Картка**: спочатку польське слово. Тап — переворот (English). Свайп або «Wstecz / Dalej» — гортати.
- **Na czarną listę (umiem)** — слово більше не з'являється на картках. «Cofnij ostatnie» повертає останнє.
- **Własny zestaw** («+ Nowy zestaw»): назва + слова списком, по одному в рядку: `śrubokręt = screwdriver`. Розділювач: `=`, `;`, табуляція або тире. Також можна знайти слова в базі й відмітити галочками. Довге натискання на власний зестав → «Dodaj słowa» / «Usuń zestaw».
- Партія B1 і власні зестави працюють паралельно; чорний список спільний.

## Як отримати APK (без Android Studio, ~10 хвилин)

Збірка йде автоматично на GitHub (безкоштовно).

1. Створи репозиторій на <https://github.com> (краще приватний).
2. Залий туди весь вміст цієї папки:
   ```
   cd slowka-b1
   git init -b main
   git add .
   git commit -m "wersja 1.1"
   git remote add origin https://github.com/ТВІЙ_НІК/slowka-b1.git
   git push -u origin main
   ```
   Якщо репозиторій уже є, просто заміни файли й зроби `git add . && git commit -m "1.1" && git push`.
   Папка `.github` прихована; вона теж має потрапити в репозиторій.
3. Вкладка **Actions** → **Build APK**, збірка триває ~5 хв.
4. Коли з'явиться зелена галочка: **Releases → Slowka B1 (latest build)** → `app-debug.apk` (або в Actions → Artifacts).
5. Перенеси `app-debug.apk` на телефон і встанови (дозволь «Невідомі джерела»).

Якщо збірка червона: відкрий лог, скопіюй текст помилки й надішли мені, виправлю.

## Альтернатива: Android Studio

File → Open → ця папка → дочекатись Gradle → **Build → Build APK(s)**. Файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Слова й фрази

- Слова: `app/src/main/assets/words.csv`, формат рядка `тема|polski|english` (понад 1500 слів, 23 теми). Рядки з `#` ігноруються.
- Фрази сповіщень: `app/src/main/assets/phrases.txt`, по одній у рядку. `{streak}` підставляє довжину серії («5 dni»); такі фрази показуються тільки коли серія є.
- База даних створюється при першому запуску. Нові слова з `words.csv` у вже встановленому застосунку не з'являться, доки не очистиш дані застосунку (прогрес при цьому скинеться).

## Структура проєкту

- `Db.java` — SQLite: слова, зестави, чорний список (+ позначка проходження тесту), партія, серія
- `StudyActivity.java` — картки й анімації; `TestActivity.java` — тест; `Answers.java` — перевірка відповідей
- `MainActivity.java` — головний екран; `PackEditActivity.java` — створення зестав; `BlacklistActivity.java` — чорний список
- `TestOffer.java` — коли пропонувати тест (50, 60, 70…)
- `Reminder.java`, `ReminderReceiver.java`, `BootReceiver.java` — сповіщення
- `Ui.java`, `Pl.java` — інтерфейсні помічники й польські відмінки («1 słowo, 2 słowa, 5 słów»)
- `.github/workflows/build.yml` — автоматична збірка APK
