# Słówka B1 — картки польська → English

Android-застосунок для вивчення слів рівня B1 (орієнтований на технікум у Польщі).
Біле меню, картки з переворотом, база даних SQLite, чорний список, партії по 50 слів і власні паки.
Без інтернету, без реклами, без зовнішніх бібліотек.

## Як користуватись

- **Партія B1** — застосунок бере 50 слів і показує їх, доки всі не підуть у чорний список. Після цього автоматично створюється нова партія з наступних 50.
- **Картка**: спочатку польське слово. Тап — картка перевертається (English). Свайп ліворуч/праворуч або кнопки «Назад / Далі» — перегортати. Після останньої картки починається перша.
- **У чорний список (вивчено)** — слово більше не з'являється ні в партії, ні в паках. Помилився — кнопка «Скасувати останнє» або «Чорний список» на головному екрані → «Повернути».
- **Теми B1** — 23 готові паки по темах (техніка, комп'ютер, здоров'я, дієслова тощо), понад 1500 слів.
- **Власний пак** («+ Новий пак»): введи назву й встав слова списком, по одному в рядку:
  ```
  śrubokręt = screwdriver
  lutować = to solder
  ```
  Розділювач: `=`, `;`, табуляція або тире. Також можна знайти слова в базі через пошук і відмітити галочками.
  Довге натискання на власний пак → «Додати слова» / «Видалити пак».
- Власні паки працюють паралельно з партією: чорний список спільний для всього.

## Як отримати APK (без Android Studio, ~10 хвилин)

Збірка йде автоматично на GitHub (безкоштовно).

1. Зареєструйся на <https://github.com> і створи новий репозиторій (наприклад `slowka-b1`).
2. Залий туди весь вміст цієї папки. Найпростіше через термінал (потрібен встановлений `git`):
   ```
   cd slowka-b1
   git init -b main
   git add .
   git commit -m "first version"
   git remote add origin https://github.com/ТВІЙ_НІК/slowka-b1.git
   git push -u origin main
   ```
   > Папка `.github` прихована — якщо заливаєш через сайт «перетягуванням», переконайся, що вона теж потрапила в репозиторій.
3. Відкрий вкладку **Actions** у репозиторії → workflow **Build APK**. Збірка триває ~5 хв.
4. Коли з'явиться зелена галочка:
   - або відкрий **Releases → Slowka B1 (latest build)** і завантаж `app-debug.apk`,
   - або відкрий збірку в Actions і внизу в **Artifacts** завантаж `slowka-b1-apk` (там zip з APK).
5. Перенеси `app-debug.apk` на телефон, відкрий його й дозволь «Встановлення з невідомих джерел» для цього застосунку.

Якщо збірка червона — відкрий її лог, скопіюй текст помилки й надішли мені, виправлю.

## Альтернатива: Android Studio

File → Open → вибрати цю папку → дочекатись синхронізації Gradle → **Build → Build APK(s)**.
Готовий файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Як змінити або додати слова в базу

Список слів лежить у `app/src/main/assets/words.csv`, формат рядка: `тема|polski|english`.
Рядки з `#` ігноруються. Після змін збери APK заново.

> Важливо: база даних створюється при **першому** запуску. Якщо оновив APK поверх старого, нові слова з words.csv не з'являться,
> доки не видалиш застосунок і не встановиш знову (або не очистиш дані застосунку в налаштуваннях Android) — прогрес при цьому скинеться.

## Структура проєкту

- `app/src/main/java/com/lerneng/b1cards/Db.java` — SQLite: слова, паки, чорний список, партія
- `StudyActivity.java` — картки (перевертання, свайпи, чорний список, скасування)
- `MainActivity.java` — головне меню; `PackEditActivity.java` — створення паків; `BlacklistActivity.java` — чорний список
- `Ui.java` — стилі та допоміжні функції інтерфейсу
- `.github/workflows/build.yml` — автоматична збірка APK
